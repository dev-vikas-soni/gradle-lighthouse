# Support Guide

We are committed to providing a great experience for Gradle Lighthouse users. If you need help, please follow the guidelines below.

## ❓ Questions & Help
For general questions about usage, configuration, or best practices, please use:
* **GitHub Discussions**: Best for open-ended architectural discussions.
* **GitHub Issues**: Use the "Question" template for specific "How do I?" queries.

## 🐛 Bug Reports
If you think you've found a bug in the plugin:
1. Search the [existing issues](https://github.com/dev-vikas-soni/gradle-lighthouse/issues) to see if it's already reported.
2. If not, open a new issue using the **Bug Report** template.
3. Provide as much detail as possible, including your environment and reproduction steps.

## ✨ Feature Requests
Have an idea to make Lighthouse better?
* Open a new issue using the **Feature Request** template.
* Explain the problem you're solving and how the feature would help.

## 🔒 Security Issues
Please see our [Security Policy](SECURITY.md) for instructions on reporting vulnerabilities privately.

## 📋 Compatibility
Gradle Lighthouse supports:
* **Gradle**: 8.0+
* **Java**: 17+
* **Android Gradle Plugin**: 7.4+

For more details, see the [Compatibility Matrix](docs/compatibility.md).
