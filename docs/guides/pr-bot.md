# The Lighthouse PR Bot

The PR Bot provides a collaborative way to maintain architectural standards by posting score deltas and cycle warnings directly in Pull Requests.

## Features

* **Score Delta**: "Health Score: 82/100 (Up +5)"
* **Module Count**: Tracks if new modules were added or removed.
* **New Cycle Detection**: Specifically flags circular dependencies introduced in the PR.
* **Regression List**: Highlights modules that dropped in health score.
* **Improvement List**: Celebrates modules where debt was resolved.

## How it works

1. **Head Run**: Lighthouse runs on your PR branch.
2. **Base Download**: The GitHub Action downloads the artifacts from your `main` branch.
3. **Delta Logic**: The `lighthouseAggregate` task compares the two datasets.
4. **Summary Generation**: A Markdown file (`lighthouse-pr-summary.md`) is created.
5. **Comment Post**: The GitHub Script in the action posts/updates the comment in the PR.

## PR Summary Example

```markdown
## 🏗️ Gradle Lighthouse Architectural Intelligence

| Metric | Value | Delta |
|--------|-------|-------|
| **Health Score** | 82/100 | Up +5 |
| **Modules** | 24 | ±0 |

### ⚠️ New Dependency Cycles (1)
- 🔗 `:app ➔ :feature:login ➔ :core:network ➔ :app`

### 🔴 Regressions
- **:feature:search**: 75% (Down -4)

> _Generated by Gradle Lighthouse PR Bot_
```

## Setup Instructions

See the [GitHub Actions Guide](github-actions.md) for the configuration steps.

## Manual Delta Running

If you are not using GitHub Actions, you can run the delta analysis locally by providing the path to a previous report directory:

```bash
./gradlew lighthouseAggregate -Plighthouse.baseReportDir=/path/to/main/reports
```
