# Security Policy

## Supported Versions

We provide security updates for the following versions of Gradle Lighthouse:

| Version | Supported          |
| ------- | ------------------ |
| 2.3.x   | ✅ Yes              |
| 2.2.x   | ❌ No               |
| < 2.2.x | ❌ No               |

## Reporting a Vulnerability

If you discover a security vulnerability within Gradle Lighthouse, please do not open a public issue. Instead, report it privately to ensure the safety of our users.

Please send an email to **vikas.soni.dev@gmail.com** with the subject **[SECURITY]**.

In your report, please include:
* A description of the vulnerability.
* The affected version(s).
* A proof-of-concept or steps to reproduce.

### Our Response Process
1. We will acknowledge receipt of your report within 48 hours.
2. We will investigate the issue and determine the severity.
3. We will work on a fix and notify you of the progress.
4. We will coordinate a release and public disclosure.

Thank you for helping keep Gradle Lighthouse secure for everyone.
